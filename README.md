# Selenium Assignments and Capstone Project

## Overview

This repository contains Selenium WebDriver assignments and a Capstone project completed using Python, Selenium WebDriver, and Pytest.

The work is organized into two separate folders:

- `Assignments/` – Contains the respective Selenium assignments completed during the course.
- `Project/` – Contains the Capstone project 1, implementing an end-to-end e-commerce purchase automation workflow.

## Project Structure

```text
Selenium-Project-Assignments/
│
├── Assignments/
│   └── Selenium Assignments
│
└── Project/
    └── Selenium E-Commerce Purchase Automation
```
